# RIPZ Raiders

Owlie collector RPG for the ohhRIPZ district. **TAKE YOUR SHOT.**

SWAP is play-money. Packs, balls, and berries are bought with SWAP earned in battles. There is no cash, no card checkout, and nothing to gamble for real money.

## Play

- Public web: open the site.
- Kiosk: add `?mode=kiosk` or open `/kiosk/`. Idle for two minutes returns to the title. The Owlie Card button hides.

## Controls

| Input | Action |
| --- | --- |
| Arrows / WASD / D-pad | Walk. **A is left, D is right.** |
| A / Enter / Z | Confirm, talk, advance text |
| B / X | Back |
| Menu / M | Menu, or advance text |
| Shift | Walk faster |

## The region

Hoot Plaza → Foil Trail → Shelfburg gym (Ember Crest) → Chrome Coast → Foil Harbor gym (Brine Seal) → Night Rip Road → Vault Spire. Vex is the rival. Aurelia holds the Vault Crown.

Gust Sweep clears bramble after the Ember Crest if a gale raider is in the party. Stone Smash breaks cracked rocks after the Brine Seal if a stone raider is in the party.

Save is on this device (one slot, autosave on every door).

## Art

Tiles are 64×64 and raider sheets are 128×128 (idle, walk, attack), drawn in the browser so the page stays a static GitHub Pages site.
